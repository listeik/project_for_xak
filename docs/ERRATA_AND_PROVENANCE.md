# Происхождение контрольных данных

Этот файл подготовлен командой для восстановления ссылки из исходного `data/README.md`.
Он не является дополнительными условиями или официальным исправлением организатора.

Контрольные CSV в `data/`, BASE и MANDATORY_STRESS в `scenarios/`, схемы в `schemas/`
и контрольные векторы в `validation/` сохранены без изменения чисел.
Первичные материалы задания находятся в каталоге `doc-1789744888/`.

Код загружает контрольные числа из файлов и выдаёт `input_version` — SHA-256-отпечаток
CSV и обязательного стрессового сценария. Это позволяет сопоставить результаты запусков
с конкретной версией входов. Сам отпечаток не подтверждает истинность входных данных.

Допущения реализации раскрыты в [MODEL.md](MODEL.md): календарь, дневной профиль,
начальный запас, подготовительные заказы, способ учёта хранения, дисконтирование
и консервативное определение планового использования Emergency.

Сведения о новых официальных исправлениях организаторов в предоставленном наборе
отсутствуют. При их получении следует обновить контрольные файлы, независимые проверки
и этот журнал с датой и ссылкой на соответствующее сообщение организатора.
